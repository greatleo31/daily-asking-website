# 留痕 Logo · AI 生图提示词（Gemini / GPT 版）

> 用法：整段复制给 Gemini（Nano Banana）或 GPT 生图。AI 只画图形不画字，
> 「留痕」两个字由开发者用字体程序化加上，保证笔画零错误。
> 生成后把 PNG（≥1024px）发给开发者即可。

## 1. 主提示词（水滴 emblem，直接复制）

```
为一款名叫「留痕」的记事 App 设计一个极简 Logo 图形，不要出现任何文字。

图形：一滴水正在落下，下方水面荡开一圈细细的涟漪弧线，寓意「水滴石穿、落水留痕」。水滴上部是柔和的尖角，下部圆润饱满接近正圆；涟漪只是一条断开的弧线，不是完整圆圈。

风格：扁平矢量线条图标，线条细且全程粗细一致，端点和转折都是圆角。没有渐变、没有阴影、没有立体感、没有背景装饰。

颜色：只用一种墨绿色 #2F4B3E 画线条，背景纯白。

构图：图形居中，四周留白充足，水滴和涟漪之间留出清晰间距。

要求：缩小到 16×16 像素时依然能认出是水滴加涟漪。输出 1:1 正方形。
```

## 2. Favicon 变体（可选）

```
设计一个 App 图标：墨绿色 #2F4B3E 的圆角正方形底，正中间画一个米白色 #F6F3EA 的水滴剪影，水滴下方一条细细的同色涟漪弧线。扁平极简，无渐变无阴影，不要任何文字。输出 1:1。
```

## 3. 挑图标准（快速四条）

1. 线条从头到尾一样粗，无渐变无阴影无杂色
2. 水滴轮廓清晰：上尖下圆
3. 缩小看仍能认出「水滴 + 涟漪」
4. 画面里没有任何文字或笔画残留

## 4. 交付

选中的 PNG 原图（≥1024px，勿裁剪）发给开发者，后处理全自动：
矢量化 → 拼「留痕」宋体字标 → 重出 favicon 全套和 OG 图 → 更新网站。
